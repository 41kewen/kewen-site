家里云建站如何用 Cloudflare + Vercel绕过⏰备案，且能让海外用户访问

(Publish) 2026.09.14 (Edit) 2026.09.15
#运维#网络#技术笔记

怎么做

1. 将站点部署到 Vercel

我先把博客构建成纯静态文件，并准备一个独立的 Vercel 部署目录。需要服务端能力的接口则迁移为 Serverless Functions；密钥只放在平台环境变量中，不写进仓库或前端代码。

部署完成后，先别急着配域名。在项目 Overview 中确认 Production Deployment 显示 Ready，顺便核对当前生效的部署和生产域名。

2. 在 Vercel 绑定自定义域名

接着进入项目的 Settings → Domains，点击 Add Existing，填入根域名和 www 子域名，再把它们连接到 Production 环境。图里的粉色箭头就是需要点击和确认的位置。

添加成功后，域名会出现在 Domains 列表中。如果 Cloudflare 已经开启代理，Vercel 可能显示 Proxy Detected。先别被黄色提示吓到：它不一定代表网站不可用，只是表示 Vercel 无法直接观察原始 DNS；代价是 Vercel 自己的一部分 DDoS 与 Bot 防护无法直接工作，需要按自己的需求取舍。

3. 在 Cloudflare 配置 DNS

然后到 Cloudflare 的 DNS → Records。点击 Add record，让根域名和 www 都指向 Vercel 要求的目标。TTL 保持 Auto 即可；如果希望访问流量先经过 Cloudflare，就打开橙云代理。

截图中的 76.76.21.21 是我配置时 Vercel 给出的地址。平台要求可能变化，实际操作一定以你自己 Vercel Domains 页面当时显示的值为准，不要机械照抄这篇文章里的旧地址。

4. 设置端到端 HTTPS

最后进入 SSL/TLS → Overview，点击 Configure，把加密模式设为 Full (strict)。这样浏览器到 Cloudflare、Cloudflare 到 Vercel 两段连接都会使用有效证书，而不是只加密前半段。

然后应该就好了
